# Exam 2 Implementation Plan

**Goal:** Deploy an Exam 2 edition of the existing study site, with the same views and independent progress.
**Architecture:** Shared app renderer and stylesheet; separate `/exam2/` static entry, question/guide content, planner, and formula definitions. No backend or build dependency.
**Tech Stack:** HTML, CSS, browser JavaScript, Node verification, Python PDF preparation.
**Spec:** `docs/superpowers/specs/2026-10-25-exam2-design.md`.

## Global constraints
Preserve Exam 1 saved state and routes. Preserve source labels. Every new domain/question is Exam 2 only. No invented deadline. Same accepted layout.

## Review focus
Cross-exam import/reset isolation; reversed versus already-negated items; PDF formula fidelity; date rollover/rescheduling; calculator invalid inputs and mobile layout.
